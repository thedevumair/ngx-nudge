1. Install the package

2. Install the extension

In VS Code or Cursor, open Extensions and search for ngx-nudge Sync. Open your project folder and choose Trust when asked. The status bar shows ngx-nudge Sync: ON (4567) when it is ready.

3. Add the dev tools once

They render nothing in production builds.

4. Your first synced table

Run ng serve, resize a column, and watch teamColumns change in your editor.

Troubleshooting

  • Status bar says OFF: the folder is in Restricted Mode. Trust it.
  • Nothing changes: open DevTools, Network, and read the response of the columns or props request. It explains what was not found.
  • No free port: close extra VS Code windows. Five run side by side.
